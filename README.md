# BOSTON TELECOM — MAHMOUD SUNNY PHONE

Site vitrine responsive en HTML, CSS et JavaScript, prévu pour un hébergement statique gratuit.

## Tester
Ouvrir `index.html` dans un navigateur.

## Publier gratuitement avec GitHub Pages
1. Crée un dépôt GitHub public nommé `boston-telecom`.
2. Envoie tous les fichiers et dossiers de cette archive à la racine du dépôt.
3. Dans le dépôt : **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
5. Attends la fin du déploiement. L'adresse sera de la forme `https://TON-PSEUDO.github.io/boston-telecom/`.

## Personnaliser
- Remplacer les images dans `assets/` si nécessaire.
- Les contacts sont configurés : WhatsApp `+237 697 55 76 71`, appel `+237 675 89 43 92`.
- Les prix et les stocks ne sont pas inventés : le site invite les clients à demander les tarifs sur WhatsApp.
- Aucun paiement en ligne ni base de données n'est configuré dans cette version.
